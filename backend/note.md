Frame Cost = Total Weight (kg) × Rate per kg (set per Aluminium Type, or per Type+Gauge if rates vary by gauge too)

Hardware Cost = fixed amount per Window/Door Type

Price per unit = Frame Cost + Hardware Cost

Total = (Price per unit × Quantity) + Worker Fee
